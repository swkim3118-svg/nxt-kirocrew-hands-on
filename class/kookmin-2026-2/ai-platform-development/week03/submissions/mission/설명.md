# 행사 준비 에이전트 설명

## 에이전트 · 스킬 이름
- 에이전트: 행사준비
- 스킬: event-prep

## 정리 기준
행사 안내 문서와 참가신청 CSV를 읽고, 매번 같은 항목(행사 안내 / 준비할 일 / 참가 신청 표 / 참가 인원수·필요 음식·생수 / 확인 필요)으로 준비할 일을 정리한다. 집계는 스크립트로 처리해 규칙과 항목 이름을 일관되게 유지하며, 집계·판단 기준은 행사안내 문서를 따른다.

## 테스트 후 수정한 점
- 참가/불참 어느 쪽도 아닌 값(오타·빈칸)이 조용히 누락되던 문제를 발견해, 이런 행을 확인 필요에 참가 여부 확인 대상으로 잡도록 수정하고 오타 CSV로 검증했다.
