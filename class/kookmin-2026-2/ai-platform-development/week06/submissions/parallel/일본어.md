# 学科AI実習の集まり

## 概要

学科の仲間たちと一緒にAIを実際に使ってみる実習の集まりを開催します。定員は12名で、AI実習が初めての学生も参加できます。英語と日本語の案内は集まりの情報を理解してもらうために提供するものであり、集まり当日の案内と実習はすべて韓国語で進行されます。開催は2026年10月16日18時30分から20時まで、場所は学生会館の集まり室で、参加費はありません。参加の際は個人のノートパソコンと充電器をご準備ください。

## 集まりの情報

| 項目 | 内容 |
| --- | --- |
| 日程 | 2026年10月16日 18:30～20:00（韓国時間 / Asia/Seoul） |
| 場所 | 学生会館 集まり室 |
| 定員 | 12名 |
| 持ち物 | 個人のノートパソコンと充電器 |
| Wi-Fi | 集まりの場所で利用可能 |
| 参加費 | なし |
| 進行言語 | 韓国語（集まりは韓国語で進行されます） |
| 参加対象 | AI実習が初めての学生も参加可能 |

## 申し込み方法

参加を希望する学生は、2026年10月14日18時（韓国時間 / Asia/Seoul）までに学科のグループチャットに名前を残してください。別途の申し込みリンクは提供されません。日付と締め切り時刻を確認したうえで、案内された方法に従って申し込んでください。
