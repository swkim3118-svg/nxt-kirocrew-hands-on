개요

빛담 가을사진전(E04) 운영 보고서. 확정 참가자는 140명이며, 승인 정원은 근거 문서 기준 160명이다. 홍보 안내(180명)와 승인 정원 사이에 차이가 있고, 180명 정원변경은 회의 메모상 '요청 예정' 단계로 승인 기록이 없어 확인이 필요하다. 회계상 학교지원금 250,000원, 동아리회비 1,843,000원의 현재 잔액이 있으며 E04 순지출은 896,000원이다. 구매계획은 확정 인원 기준 460,000원이 필요하고, 정원을 160·180명으로 늘릴 경우를 대비한 예정 비용도 함께 계산했다.

승인 정원 160명 근거 APPROVAL-SPACE-04(장소 승인 정원) + 공간이용안내 RULE-02

홍보 정원 180명 — 확인 필요 — 주입된 지식만으로는 정원변경 승인 확인 불가

가능한 운영안

안 A — 확정 140명 기준 진행 (보수적)

승인 정원(160) 이내이고 대기자를 추가 전환하지 않는 안. 구매 예정 460,000원(학교지원금 256,000 / 회비 204,000). 정원변경 승인 여부와 무관하게 즉시 확정 가능하며 재원도 충분하다.

근거: CLUB-01 제1·3조(기본 인원=확정, 대기자 미가산), APPROVAL-SPACE-04(정원 160)

안 B — 160명까지 대기자 전환 (승인 정원 소진)

대기 40명 중 20명을 신청 순서대로 전환해 160명을 채우는 안. 구매 예정 510,000원(학교지원금 284,000 / 회비 226,000). 승인 정원 한도 내라 별도 정원변경 승인이 필요 없다. 준비물·재원·정원을 함께 확인한 뒤 순서대로 전환한다.

근거: CLUB-01 제3조(정원·물품·재원 확인 후 순서 전환), APPROVAL-SPACE-04(정원 160)

안 C — 180명 확대 (정원변경 승인 전제)

홍보 안내(180명)에 맞춰 대기 40명을 모두 전환하는 안. 구매 예정 560,000원(학교지원금 312,000 / 회비 248,000). 단, 승인 정원을 180으로 올리는 정원변경 승인이 선행되어야 하며 현재 근거로는 승인 기록이 없다. 승인 없이는 실행 불가.

근거: MEMO-04(180 변경 '요청 예정', 승인 기록 없음), APPROVAL-SPACE-04(현 정원 160)

추가 확인 사항

  • 정원변경 승인 여부 — 승인 정원을 160→180으로 올리는 정식 변경 승인서가 발급됐는지 확인 필요. 미발급 시 유효 정원은 160명.
  • 외부인 참가 가능 여부 — MEMO-04에 '이 회의에서 결정하지 않았다'고 명시. 동아리운영규칙·행사안내의 참가 자격 조항 확인 필요.
  • 식음료 지원 상한 — RULE-01 제2조상 확정 참가자 1인 4,000원 이내, 최종 정산 시 실제 참석 인원·증빙 대조. 식음료 신청 112명 기준 예산 별도 점검 필요.
  • 기념품 재원 — 기념스티커 등은 학교지원금 지원 제외(RULE-01 제3조)로 회비 처리. 회비 기념품 1인 3,000원 이내·결재·영수증 요건(CLUB-01 제2조) 준수 확인.
  • 구매계획은 예정치 — ACCOUNT-01 제4·5조에 따라 회계 거래·기지급 비용에 합산하지 않음. 실제 집행 시 증빙과 대조.
